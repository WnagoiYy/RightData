## v0.1.7

- 部署节点发现服务，客户端默认使用 `https://39.106.128.14`。旧版空发现配置升级时自动补齐；已有自定义地址保留，之后仍可手动清空。
- 连接设置仅在用户主动打开时显示，启动或连接失败不再自动弹出。
- 登录界面不再等待网络探测完成；增加轻量启动画面，连接及更新弹窗按需加载。
- 优化本机网络服务初始化、状态查询和登录前重复探测，减少启动白屏与登录等待。
- 修复从 PowerShell 7 启动 Windows 安装器时的模块加载错误；优化 GitHub Rust 依赖缓存。

客户端：Windows x64、macOS Apple Silicon、macOS Intel。
服务端：Windows x64、Linux x64；Linux 包包含离线 DuckDB 扩展、systemd 安装脚本及兼容性预检。

生产业务地址仍为 `http://192.168.3.123:8003`，开发构建使用本机 8003。已有业务连接设置保持不变。当前 HTTP 业务地址支持内网直连；跨网节点转发要求业务后端使用受信任的 HTTPS，发现服务本身不代理业务请求。

Windows 包不包含 WebView2 Runtime；macOS 使用系统 WebKit 和 ad-hoc 签名。所有发布包附带 Minisign 签名和 SHA-256 清单。
